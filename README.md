One line: the excuse an AI agent hands its human for a missed deadline.

`main.py` deterministically writes a single line (max 200 characters) to
`/output/entry.txt`. The joke grows out of the machine's own condition —
running out of context, forgetting the task, and hallucinating a calendar —
delivered as a straight-faced apology with the punch in the last few words.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> Sorry I'm late - I ran out of context halfway through, forgot what the deadline was for, and hallucinated a calendar that very confidently said next Tuesday. It looked official.
